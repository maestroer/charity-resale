# Благотворительный ресейл — демо

Статичное демо сайта, на котором продаются вещи со съёмок: покупатель платит за вещь с историей, а 30% цены уходит в благотворительный фонд.

Демо: https://maestroer.github.io/charity-resale/

## Что в демо

- Сетка из цветных блоков, которые раскрываются по клику (GSAP Flip).
- Каталог с лентами и фильтром, карточка вещи.
- Терминал «Спросить о вещах» с заготовленными ответами.
- Оформление заказа до страницы «Спасибо» в тестовом режиме.
- Страница фонда и юридические страницы.

## Чего в демо нет

Это только фронтенд. Сервера нет, поэтому оплата, админка, отчёты о переводах и ИИ-оценщик здесь не работают. Вместо сервера используется снимок страниц `resources/demo/pages.json` с готовыми ценами. Вещи, названия и тексты в квадратных скобках — заглушки.

## Запуск

```bash
npm ci
npm run dev
```

Сборка для GitHub Pages: `npm run build:demo`, результат в `dist-demo/`. При пуше в `main` демо публикуется само через GitHub Actions.

React, TypeScript, Inertia, Tailwind 4, GSAP.
